# 错误合集

> 下边的这些错误是同学们在第一次上机课的时候经常问到的，我们把它们整理在一起，方便大家查阅。

## 一、语法基础错误

### 1. 忘记分号 `;`

**错误：**

```c
#include <stdio.h>

int main()
{
    int a = 10
    printf("%d", a);

    return 0;
}
```

**报错原因：**

C语言中大部分语句必须以 `;` 结束。

**正确：**

```c
int a = 10;
printf("%d", a);
```

### 2. 大括号 `{}` 不匹配

在嵌套层级比较多的时候，会有很多的大括号，这个时候就很容易出现大括号不匹配的情况，包括多余的大括号和缺少的大括号。

**比如：**

**错误：**

```c
if(a>0)
{
    printf("a>0");
}
else
{
    printf("a<=0");
```

这就是很经典的缺少大括号的情况。

### 3. 中文符号导致编译错误

**错误：**

```c
printf（"hello"）；
```

**这里：**

```text
（）
；
```

都是中文符号，各位在写代码的时候一定要使用英文输入法。

## 二、变量相关错误

### 4. 使用变量前没有定义

**错误：**

```c
a = 10;

printf("%d", a);
```

**原因：**

C语言要求变量先声明。

**正确：**

```c
int a = 10;
```

### 5. 变量未初始化

**错误：**

```c
int a;

printf("%d", a);
```

**原因：**

局部变量默认没有初值，这时候可能输出的是随机的值。

### 6. 变量名非法

**错误：**

```c
int 2num;
int int;
int hello-world;
```

上边的写法都是错误的。C 语言的变量名只能以数字、字母、下划线组成，并且不能以数字开头，不能使用关键字。

上边的 `2num` 以数字开头，`int` 是关键字，`hello-world` 中间有 `-`，所以都是非法的。

## 三、数据类型错误

### 7. printf格式符错误（非常常见）

**例如：**

```c
float pi = 3.14;

printf("%d", pi);
```

**输出：**

```text
0
```

原因在于 `pi` 是 float类型，浮点数，而 `%d` 是整数类型的格式符，这时候类型不匹配，编译器就只会输出 0.

**正确：**

```c
printf("%f", pi);
```

**常用格式：**

| 类型   | printf |
| ------ | ------ |
| int    | `%d`   |
| float  | `%f`   |
| double | `%lf`  |
| char   | `%c`   |
| 字符串 | `%s`   |

### 8. 整数除法导致结果错误

**错误：**

```c
int a = 5 / 2;

printf("%d", a);
```

**输出：**

```text
2
```

5 / 2，结果是 2.5，应该是一个 float 类型，但是代码却用了一个 `int` 类型来接收结果，这时候程序就会直接丢掉小数部分，只保留整数部分。所以输出的结果是 2，而不是 2.5。

**正确：**

```c
float a = 5.0 / 2;
```

## 四、输入输出错误

### 9. scanf忘记加 `&`

**错误：**

```c
int a;

scanf("%d", a);
```

**正确：**

```c
scanf("%d", &a);
```

**原因：**

scanf需要变量地址。这里的 `&` 是取地址符，表示我要获得变量 a 的地址。知道了地址，scanf 才能把输入的值存储到 a 里面。

### 10. scanf格式符错误

**错误：**

```c
float x;

scanf("%d",&x);
```

这个错误和 `printf` 格式符错误是一样的，`x` 是 float 类型，而 `%d` 是整数类型的格式符，类型不匹配。

## 五、条件语句错误

### 11. 把赋值 `=` 写成判断 `==`

**错误：**

```c
if(a = 5)
{
    printf("yes");
}
```

这里的 `=` 是赋值符号，表示把 5 赋值给 a，这个条件语句永远成立，所以会一直输出 yes。

如果想比较 a 是否等于 5，应该使用 `==`，也就是两个等号，不等于是 `!=`。

### 12. if没有大括号导致逻辑错误

**错误：**

```c
if(score>=60)
    printf("pass");
    printf("good");
```

`if` 后边，如果没有大括号，那么表示只有紧跟着的那一条语句是条件语句，后边的 `printf("good");` 是无条件执行的。

那么当 `score` 大于等于 60 的时候，输出：

```text
passgood
```

当 `score` 小于 60 的时候，输出：

```text
good
```

**正确：**

```c
if(score>=60)
{
    printf("pass");
    printf("good");
}
```

## 六、循环错误

### 13. 死循环

**错误：**

```c
int i = 0;

while(i<10)
{
    printf("%d",i);
}
```

这里的循环会一直执行下去，因为 `i` 的值永远不会改变，所以条件 `i<10` 永远成立。

同学们在写循环的时候，一定要注意循环条件和循环变量的变化，不要写出死循环。

**正确：**

```c
int i = 0;

while(i<10)
{
    printf("%d",i);
    i++;
}
```

### 14. 数组越界

**错误：**

```c
int a[10];

a[10]=100;
```

这里定义了一个数组变量 `a`，他的大小是 10，也就是下标是从 0 到 9，所以这时候我们访问 `a[10]` 是不合法的，属于数组越界。

## 七、字符串错误

### 15. 字符和字符串混淆

字符用单引号 `'` 包起来，字符串用双引号 `"` 包起来。

```c
char c='A';
char str[]="ABC";
```

## 八、函数错误

### 16. 函数声明缺失

**错误：**

```c
int main()
{
    add(1,2);
}
```

函数要先声明，再使用。

**正确：**

```c
int add(int a,int b);

int main()
{
    add(1,2);
}

int add(int a,int b)
{
    return a+b;
}
```

### 17. 忘记return

**错误：**

```c
int add(int a,int b)
{
    return a+b;
}
```

## PTA 常见错误

PTA 上最常见的就是“格式错误”，由于 PTA 的输出要求非常严格，哪怕是多了一个空格或者少了一个换行符，都会被判为错误。

所以各位同学在做题的时候，建议直接把标准输出复制到自己的代码里面，然后进行替换。

**比如：**

```c
fahr = 100, celsius = 计算所得摄氏温度的整数值
```

直接把这段话放进 `printf` 里面，然后把对应的变量替换掉就可以了。

```c
printf("fahr = 100, celsius = %d\n", celsius);
```
